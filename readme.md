# Mini Factory

Mini Factory is a small 2D factory simulation game inspired by Factorio.

The project is written in C++ using raylib.
The main goal is to learn the basics of game development: game loop, input handling, grid-based world, placing buildings, simple resource production, and rendering.

## Project Idea

The player builds a small factory on a tile-based map.

The first version will include:

* Grid-based world
* Ore tiles
* Miner building
* Chest building
* Resource counter
* Basic building placement

## Planned Controls

* `1` — select Miner
* `2` — select Chest
* Left Mouse Button — place selected building
* Right Mouse Button — remove building

## Main Systems

* Game loop
* World grid
* Cells / tiles
* Buildings
* Items
* Input handling
* Rendering

## Technology

* C++
* raylib
* CMake
